## 本地行为检查

以下命令从仓库根目录执行。配置`ANDROID_HOME`与可运行Gradle的JDK；Kotlin/Native测试需要macOS、Xcode及iOS Simulator运行环境。Node测试转译真实ArkTS源码并使用受控SDK替身，`TYPESCRIPT_PATH`可指定已有TypeScript模块。

```sh
bash gradlew :permission-core:testDebugUnitTest :permission-core:compileKotlinIosSimulatorArm64 --max-workers=1
bash gradlew -p verification-kuikly test --max-workers=1
node --test ohos/permission-native/test/permission.test.cjs
```

只运行受影响目标；需要确认本轮真实执行时加`--rerun-tasks`，不要把`UP-TO-DATE`算成新执行。平台测试结果XML位于`permission-core/build/test-results/`；独立Module测试结果在`verification-kuikly/build/test-results/test/`。这些测试不调用真实分享、认证、拨号或定位业务。

## 原生产物与独立消费

HarmonyOS工具链需要DevEco SDK、ohpm与hvigorw。在`ohos/`目录执行：

```sh
ohpm install --all
hvigorw --mode module -p module=PermissionNative@default -p product=default assembleHar --no-daemon
```

安装与公开API消费工程按[接入指南](接入指南.md)和[README](../README.md)执行。构建/本地HAR消费不等于OHPM Registry或本版远程消费。Maven、Swift/Pod与HAR按各自版本验证。

## 结果与历史记录

本轮源码修复验证：`verification-kuikly` 同时编译生产 iOS Permission 文件，`IosPermissionLifecycleTest` 检查相机取消→麦克风、定位取消→排队请求取消→麦克风、重复旧回调隔离。AVFoundation/CoreLocation 为测试 SDK 替身；本轮实际 iOS Simulator Kotlin/Native 编译通过，真实授权弹窗/RunLoop 尚未验收。

本次候选的测试入口、实际执行平台、复用/新执行时点和未验收范围统一维护在[功能页验证范围](功能与平台差异.md#验证范围)。[权限历史验收](../verification/验收记录.md)、[0.1.3发布验收](发布验收-0.1.3.md)保留原记录时点，不证明当前候选已经发布或完成设备业务验收。
