# permission 功能与平台差异

适用版本：Maven 0.1.7；HAR 0.1.6沿用原字节。源码基线：`2789f8184303afb76a7f6a424ce862f1ebf2a8c2`，叠加本次修复；最终源码由不可变Git标签`0.1.7`定位。构建、checksum及各渠道实际验收结果见[版本发布记录](https://github.com/gycrosskit/permission/releases/tag/0.1.7)，源码/替身测试范围见本页验证表；不声明真实设备业务验收通过。

## 产物与职责

| 模块/产品 | 实际职责 |
|---|---|
| `permission-core` | PermissionPlatform.getStatus/request/resumeAfterSettings、AppPermission、PermissionStatus；Android/iOS实现。 |
| `permission-kuikly` | 仅ohosArm64 PermissionModule，名称GycPermission；120秒桥等待和页面dispatcher。 |
| `@gycrosskit/permission-native` | API22 HAR，GycPermissionService和GycPermissionModule；直接ArkTS可使用service。 |

构建边界：[core构建](../permission-core/build.gradle.kts)、[Kuikly构建](../permission-kuikly/build.gradle.kts)、[模块清单](../settings.gradle.kts)、[OHOS SDK配置](../ohos/build-profile.json5)。

除上表明确的 UI 入口外，本库没有独立 CMP 页面模块。Android/iOS 可由宿主原生适配把同一能力供 CMP 与 Kuikly 使用；“可注入两套UI”不代表库自动完成宿主接线、同名 Renderer 注册或品牌验收。

## 五入口功能矩阵

“原生实现，宿主注入”表示平台能力已有源码，CMP/Kuikly由宿主适配接入；“OHOS Module已实现”表示已有Kotlin/ArkTS调用链。矩阵说明功能接入边界，实际行为验证见下方验证范围。

| 功能/API组 | CMP Android | CMP iOS | Kuikly Android | Kuikly iOS | Kuikly OHOS |
|---|---|---|---|---|---|
| getStatus：三种能力 / 五种状态 | 原生实现，宿主注入 | 原生实现，宿主注入 | 原生实现，宿主注入 | 原生实现，宿主注入 | OHOS Module已实现 |
| request / 系统弹窗串行 | 原生实现，宿主注入 | 原生实现，宿主注入 | 原生实现，宿主注入 | 原生实现，宿主注入 | OHOS Module已实现 |
| resumeAfterSettings | 原生实现，宿主注入策略 | 原生实现，宿主注入重读 | 原生实现，宿主注入策略 | 原生实现，宿主注入重读 | Module策略，见差异 |
| AndroidRuntimePermission扩展 | A扩展/宿主注入 | 不支持A扩展 | A扩展/宿主注入 | 不支持A扩展 | 不支持A扩展 |

## 公开 API 组

- `PermissionPlatform.getStatus(AppPermission)` / `request` / `resumeAfterSettings`；能力CAMERA/MICROPHONE/LOCATION_WHEN_IN_USE，五状态及allowsUse由common声明。
- Android额外`bind` / `unbind`、`AndroidPermissionRequestHistory`与`AndroidRuntimePermission`执行器；Kuikly Module页面退出`dispose()`。

## API 合同与差异分类

| 分类 | 具体输入 / OS / SDK边界 | 调用方应如何处理 |
|---|---|---|
| 组件边界 | 公共仅CAMERA/MICROPHONE/LOCATION_WHEN_IN_USE；NOT_DETERMINED/GRANTED/LIMITED/DENIED/RESTRICTED。 | allowsUse仅GRANTED/LIMITED；无后台定位、整库相册或设置页跳转API。A独立AndroidRuntimePermission四状态扩展不是公共五状态的同名替代。 |
| 厂商限制 | 粗略位置A/O及iOS14+ reducedAccuracy返回LIMITED。 | LIMITED可继续使用，但不能承诺满足业务精度；权限不等于定位服务开启。 |
| 组件边界 | 设置恢复：A getStatus为DENIED时受控request；i重读；OHOS原生service只重读，KotlinModule为NOT_DETERMINED时request。 | 这是当前各入口的恢复策略差异；宿主应在明确返回设置时调用，不把它当全平台纯查询或自动弹窗。 |
| 组件边界 | A候选调用API23公开isPermissionRevokedByPolicy；本库minSdk24。 | 完整/粗略授权优先，否则policy限制映射RESTRICTED；企业管理员实机尚未验证。 |
| 厂商限制 | 取消不能关闭系统权限弹窗。 | Android/iOS串行屏障与O进程队列等待实际回执；页面销毁跳过未开始的请求，旧回执不交给新owner。 |
| 宿主职责 | A绑定/解绑当前ComponentActivity与历史namespace；iOS14+声明用途；OHOS目标/兼容API22声明实际权限。 | 维护页面生命周期、解释文案与设置页导航，组件不决定申请时机。 |
| 未验收 | 真实系统prompt、每次询问、设置往返、企业策略和品牌说明文案。 | mock与状态resolver测试不证明用户授权或市场合规验收。 |

| 前轮代码复核，复用 | Android Robolectric，16例 | [状态映射](../permission-core/src/androidUnitTest/kotlin/io/github/gycrosskit/permission/AndroidPermissionStatusResolverTest.kt)及[运行时权限](../permission-core/src/androidUnitTest/kotlin/io/github/gycrosskit/permission/AndroidRuntimePermissionTest.kt)：策略限制、粗略定位、历史恢复、取消与迟结果；launch失败不写历史 | 16例通过；系统权限UI为替身 |
| 前轮代码复核，复用 | Node转译OHOS生产源码，4例；iOS Kotlin编译 | [OHOS测试](../ohos/permission-native/test/permission.test.cjs)：状态、非法输入、销毁迟回执、全局弹窗队列与取消屏障 | 4例通过；iOS只证明编译，本轮没有iOS原生行为回归 |
