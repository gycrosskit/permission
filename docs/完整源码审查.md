## 结论与修改

Android Launcher 注册/启动异常释放请求并向上传播，只有启动受理后记录权限历史，避免把系统启动失败误判为用户拒绝或永久拒绝。HAR 根入口补导出公开签名依赖的 GycPermission / GycPermissionStatus。回调完成使用显式 hasRequested=true，不依赖尚未落盘的历史；无需更改正常 DENIED 分类。

## 最低系统与线程

Android：API24+；iOS：iOS14+；OHOS：实际 target/compatible API22。Android 权限注册/申请/取消与 iOS 权限 manager 在 Main；HAR 使用宿主 UIAbility 的权限上下文。

## 公开调用链

- PermissionPlatform / PermissionStatus → Android ActivityResultRegistry → 共享申请历史 → continuation / unregister 清理。
- IosPermissionPlatform → AVFoundation / 独占 CLLocationManager delegate → Main 查询、结算及取消清理。
- PermissionModule → GycPermissionModule → GycPermissionService → Ability 权限 API；Index 导出公开服务和签名类型。
